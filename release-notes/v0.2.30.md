# Alpha 0.2.30

Managed Codex sessions can ask Alpha to take these actions and receive the result in the originating session.

- Create Gallery and Research projects, update status, category or pinning, and create, rename or remove eligible persistent report tabs. Removing a report tab from navigation preserves its file and existing link.
- Open, activate and close eligible app tabs, and control 3D and Messages visibility for the eligible conversation. Alpha confirms the applied view state. Terminal stops remain unavailable through worker requests.
- Request one-time approval in Questions to copy an eligible registered Markdown report, add a missing final newline, or run the bundled alpha-runtime-check diagnostic. These actions use exact targets and revisions.
- Request one-time approval to import an eligible Codex skill, Markdown knowledge entry or reusable Markdown agent definition into the requesting project. Alpha checks the source, destination layout and supported reference mappings before applying the reviewed import.
- Read durable owner denials, distinct system blocks with a next step, and unconfirmed outcomes in the receipt. Alpha can retry one proven no-effect transient host failure after revalidating the same authority and target. Uncertain effects are never retried automatically.

The bridge supports managed Codex. Live managed Codex and installed WebView2 acceptance remain pending. Current file operations and script execution are limited to the actions above, with one-time approvals for gated file, import and diagnostic actions.
