Alpha 0.2.22 prepares project workspaces, repository controls and a simpler
conversation and Workspace interface.

- Top menus are exclusive and dismissible, with keyboard navigation and
  accessibility controls. Projects terminology replaces the older card wording.
- New project layouts use `projects/<stable-id>/workspace`, with an optional
  `github` sibling. Guarded journals protect lossless workspace operations.
  Existing pinned checkouts and active sessions remain in place; no live
  checkout migration is performed by this release preparation.
- Conversations is the protected default project. The + create flow creates
  projects without exposing controls that could remove the default.
- Delete project removes the project from Alpha while keeping local files.
  It does not delete a remote repository.
- Project settings keep owned working repositories and read-only source
  repositories independent, with asynchronous cloning and coordinator
  association. Read-only source repositories remain research material.
- Create repository is available only for a blank working repository setting.
  Account ownership is verified, and retries preserve the existing operation
  rather than creating duplicate repositories.
- Conversation status shows current activity and Needs attention.
- Six separate singleton Workspace utility tabs retain their open state.
- The File menu no longer offers Open/Close commands. QuickSwitcher and its
  Ctrl+K shortcut have been removed.

Focused local verification recorded 243 service tests passed and one skipped,
seven Rust tests passed and one ignored, successful build and lint, and focused
UI review with 25 screenshots. A report-height regression was corrected.
Installed native interactions remain unverified. No live migration or test
remote-repository creation was performed. These checks do not establish
publication, installation or observed continuation.

release commit. Tag publication promotes that immutable tested MSI and update
manifest without rebuilding or repeating the full suites, verifies provenance,
installer structure and signing status, and checks both public assets.
