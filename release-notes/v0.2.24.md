# Alpha 0.2.24

- Workspace project cards link to their configured GitHub repository and show logical file size in decimal units. Local deletion previews use the same measurement and explain that disk space freed may differ.
- View contains the former Tools commands. The ellipsis beside the window controls opens Settings. Help → Check for Updates opens the manual updater and restart notes.
- Questions has a permanent Workspace tab. Pending questions stay tied to their original conversations and workers, and their arrival leaves the selected document in place.
- The upgraded host moves the registry, its previous copy and shared report assets to the Workspace root on startup. Project paths and report routes stay stable. See the [cutover and rollback procedure](https://github.com/william-pyle/Alpha/blob/v0.2.24/docs/releasing.md#workspace-root-cutover).
- Codex folder trust remains manual. With scoped review enabled, recognized requests for folders under C:/Projects appear in Needs attention when Alpha cannot verify safe automation.
