# Alpha 0.2.25

- Settings → Performance Diagnostics can capture the next operation and export its timing locally. It starts off, can be stopped or disabled, and records allowlisted timing metadata without prompts, transcripts, or credentials.
- Close the Questions tab with × and reopen it from View → Questions. Pending items, drafts, and answer routing are preserved.
- Enter adds a line. Alt+Enter uses the single Submit or Append button. Alpha queues follow-ups behind active work, and Codex uses its native queue when recognized. Busy Claude sends remain blocked where no safe queue action is verified.
- Conversation tabs show names, message or terminal icons, status, and a close control. Closing a tab keeps its conversation, draft, and running work available through Conversation history.
- Needs attention separates current items from retained historical errors and preserves links to their origins.
- File no longer includes Undo last organization change. Organizational records and other undo behavior are preserved.
