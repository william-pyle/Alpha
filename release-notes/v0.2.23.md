Alpha 0.2.23 adds project storage controls and explicit local deletion.

- Project cards display Windows size on disk, measured in the background with
  compression and hardlink accounting. Right-click to refresh cached usage.
- Clear build folders previews supported generated output and requires the
  project ID before deleting it. Git-tracked files and active project workers
  are protected; changed previews must be reviewed again.
- Delete project offers keeping files or permanently deleting the complete
  canonical local project folder. GitHub repositories are never deleted.
  Built-in projects, shared paths, foreign checkouts and active work are blocked.
  Interrupted file deletion keeps a durable recovery record and can be retried.
- Delete conversation is available in the context menu and Conversation history.
  It removes Alpha records while retaining provider-native history. Active
  workers and pending Questions must be resolved first.

Focused validation uses disposable projects and conversations. Native Windows
storage tests cover compression, sparse files, hardlinks and junctions. Service
tests cover stale previews, ownership, active workers, local-file deletion,
recovery and persistence. UI checks exercise the card display and dialogs.
No live project or conversation is deleted by installing this release.

Publication promotes the immutable artifact from successful main CI on the exact
release commit. Installation and observed native operation remain separate
verification states. Windows x64 MSI; unsigned under the existing signing policy.
