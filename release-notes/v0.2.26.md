# Alpha 0.2.26

- Run an opted-in Workspace tool from its report tab and refresh the report after it finishes. Overview retains its tool controls.
- The registered Shared Drive tab uses scoped local-mirror access for image previews, text reading, and revision-checked saves to existing `.txt` files. Scan, sync review, and Explorer keep their existing roles.
- Common agents, Alpha health, and What I've learned close from the Documents tab strip. Each can reopen from View.
- Alpha checks Windows CLI locations more reliably when profile variables are incomplete. Updates initiated by this version wait for a successful MSI installation before relaunching in the originating user's unelevated session when Windows does not require a reboot.
