# Alpha shared library

This library supplies reusable skills, knowledge, workflows, scripts and report
templates. Read LIBRARY.md and the relevant skill for the current task. Follow
the active project's own instructions and keep project-specific information there.

Resolve relative references inside a skill against that skill's location. Helper
files elsewhere in the library are relative to this library root. Write task
deliverables, Workspace cards and generated media into the active project.

Read only material relevant to the task. A bundled skill does not connect an
external provider, install an optional tool, grant permission to spend money or
authorize restarting applications. Preserve the user's selected model and settings.

Store reusable additions in shared knowledge or workflows. Keep credentials,
conversations, account configuration and project records out of the release package.
Local changes survive updates; review incoming packaged versions when they conflict.
